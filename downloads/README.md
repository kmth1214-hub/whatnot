직접 다운로드가 시작되지 않으면 GitHub에서 해당 파일을 열고 **Download raw** 버튼을 누릅니다.

카탈로그 기준 CSV의 수치와 행 수는 기존 다운로드 패키지와 동일합니다.
이번 배포에서는 비공개 발주서 추출 결과를 제외하고, 생성 예시 소스를 익명화된 저장소 버전으로 바꿨습니다.
원본 파일과 기존 작업 결과는 유지했습니다.

전체 카탈로그의 전문 검수본은 아닙니다. 확인된 정확 치수·공급 범위와 미검수 OCR 검토 자료가 구분되어 있습니다.
회사 항목명·코드는 별도 확정이 필요하며, 미확정 값으로 자동 자재코드 치환을 수행하지 않습니다.
