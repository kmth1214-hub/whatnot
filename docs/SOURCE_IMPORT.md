# 소스 반입 기록

기존 `whatnot` 체크아웃에는 커밋과 프로젝트 파일이 없었습니다.
이 세션에서 작성한 `/workspace/pdf_extraction` 아래의 원본 Python 모듈 11개를 선별해 복사했습니다.
원본 작업 폴더와 기존 산출물은 수정하거나 삭제하지 않았습니다.
생성물에 중복 포함된 `deliverables/scripts/` 복사본은 중복 커밋하지 않았습니다.

## 반입한 내용

- 카탈로그 OCR·숫자 검토·JSON 검증·패키징 모듈 4개
- 치수 기준 데이터 및 SharePoint CSV 생성·검증 모듈 4개
- 익명화된 발주서 대응 예시 모듈 2개
- SharePoint 목록 구성 예시 모듈 1개
- 아키텍처 Mermaid·Graphviz 원본과 설명 문서
- 사용 의존성 목록과 로컬 실행 안내

## 공개용 복사본의 조정

- 실제 발주 식별자는 `DEMO001`, `DEMO002` 등 가상 식별자로 바꿨습니다.
- 예시의 상업 조건·가격·날짜·도착지 및 특정 발주 원문은 가상 데이터로 바꿨습니다.
- 업로드 파일의 내부 식별자가 포함된 절대 경로를 제거했습니다.
- 문서 입력 폴더와 OCR JSON 입력 경로는 실행 시 지정할 수 있도록 바꿨습니다.
- 환경변수 이름만 코드와 문서에 두고 실제 환경변수 값과 자격증명은 넣지 않았습니다.

이 작업은 기존 분석 도구의 소스 보관입니다. 웹 애플리케이션이나 API 서버, Power Automate 흐름을 새로 구현하거나 배포하지 않았습니다.
