OCR → SHAREPOINT → EXCEL

문서의 추출값을,
우리 회사의 업무 기준으로.

관리자가 등록한 기준과 일치하면 회사의 품명·코드로 바꿉니다.
일치하는 기준이 없으면 추출된 값을 그대로 엑셀 양식에 입력합니다.

기준이 바뀌면, 표만 수정하세요.SharePoint 목록에서 관리자가 직접 항목을 추가·수정합니다. 다음 처리부터 저장된 기준을 조회해 적용하는 구조입니다.
01 / WORKFLOW

문서 한 건이 처리되는 과정

기존 OCR 솔루션을 활용하고, Power Automate가 매칭과 엑셀 작성을 연결합니다.

01 OCR 솔루션

문서 업로드·추출

품명, 치수, 강종 등
문서의 항목별 값을 추출

02 Azure Blob

결과 JSON 저장

추출 결과를 저장하고
결과 ID와 저장 경로 연결

03 Power Automate

결과 ID로 조회

완료 알림의 결과 ID로
해당 JSON을 찾아 읽기

04 SharePoint

관리 기준표와 매칭

각 품목의 치수·강종 등
지정된 조건을 함께 비교

05 부서별 Excel

양식에 자동 입력

매칭 여부에 따라 값을 결정하고
정해진 시트·열에 입력

✓ 기준 1건 일치등록된 회사 품명·코드로 치환하여 입력
— 일치 기준 없음추출값 그대로 입력 · 매칭 상태 함께 표시

연결 방식 예시: OCR 저장 완료 → PA에 결과 ID 전달 → ID에 연결된 Blob 경로 조회 → JSON 읽기. 결과 ID는 업무용 식별자이며, ID와 경로의 연결 정보는 저장 메타데이터 또는 DB에서 관리합니다.

02 / MANAGE

관리자가 직접 바꾸는 기준표

SharePoint 목록의 ‘추가’ 또는 ‘격자 보기에서 편집’으로 관리합니다.

SharePoint 제품 매칭 기준표 예시. 아래 값을 직접 수정할 수 있습니다.
제품 종류두께 mm너비 mm강종회사 품명내부 코드삭제
✎
화면 개발 없이 기준을 유지·관리
관리 권한이 있는 담당자가 제품 조건과 적용할 품명·코드를 등록합니다. 이 예시 표에서도 셀을 수정하거나 행을 추가해 보세요.
기준표와 제품 정보는 모두 설명을 위한 가상 데이터입니다.
03 / TRY IT

이번 문서의 추출 결과

샘플 JSON
resultId: OCR-DEMO-001
blobPath: results/OCR-DEMO-001.json

01관리자에게는 기준표 편집 권한

SharePoint 목록 권한으로 편집자를 지정합니다. 기준 변경 이력을 남기고, 저장된 최신 기준을 다음 처리에 적용합니다.

02원문과 적용값은 함께 보관

치환한 품명·코드와 별도로 원문 추출값과 결과 ID를 보관합니다. 미매칭 품목도 엑셀에 입력해 담당자가 확인할 수 있습니다.

03부서별로 정해진 양식에 입력

대상 템플릿과 입력 위치는 미리 정합니다. 기준이 여러 건 일치하거나 필수 값이 누락되면 임의 치환 없이 확인 상태로 표시합니다.
