# 부서별 엑셀 자동 작성 아키텍처

현재는 설계안이며 실제 PA 흐름, SharePoint 목록, HTTP API 또는 Office Scripts를 배포하지 않았습니다.

담당자는 SharePoint 기본 목록 편집으로 기준값과 셀 위치를 관리하고, 문서 라이브러리에서 엑셀 템플릿을 관리합니다.
처리 시에는 사용할 기준표·매핑·템플릿의 버전을 고정해 작업 도중 설정이 바뀌어도 결과가 섞이지 않도록 합니다.

## 역할

- SharePoint: 문서 접수, 수치 기준표, 셀 매핑, 템플릿, 검토 목록, 결과 파일, 처리 기록 저장.
- Power Automate: 이벤트 처리, 설정 조회, HTTP 호출, 완료 대기, 분기, Office Scripts 실행, 메일 전달.
- 추출 API: 텍스트 PDF는 직접 추출하고 스캔본은 OCR한 뒤 품목·치수·단위 등 구조화 JSON을 반환.
- 검증 API: 선택된 기준과 추출값을 비교하고, 범위·단위·중복 후보·미확정 항목을 검사. 추출 API와 같은 서버에 구현할 수 있습니다.
- Office Scripts: 선택한 템플릿 복사본에 시트·셀 매핑대로 값을 입력. 원본 템플릿을 처리 결과로 덮어쓰지 않습니다.
- 담당자 검토: 미확정 값을 건별로 보완하거나 공통 기준을 수정하고 재검증합니다.

검토 후에는 수정된 값과 설정 버전을 다시 조회해 기존 추출 결과로 재검증합니다. 단순 값·기준 수정 때문에 OCR을 반복하지 않습니다.

## HTTP 처리

오래 걸리는 OCR은 요청에 작업번호를 반환한 뒤 완료 Webhook 또는 상태 조회로 이어집니다.
완료 결과를 받은 PA가 이후 검증·엑셀 생성·전달을 진행합니다. Webhook 수신은 다운로드 화면을 의미하지 않습니다.
오류·시간 초과는 같은 작업번호의 오류 기록으로 남기고 재시도 또는 확인 필요 경로로 처리합니다.

## 데이터와 파일 전달

PA 실행용 JSON에는 업무에 필요한 값과 상태, 작업번호, 적용 규칙 버전을 담습니다.
원본 페이지·좌표·근거는 별도 검토 기록으로 보관할 수 있으며 매번 PA 입력에 포함할 필요는 없습니다.
완성된 엑셀은 SharePoint에 보관하고 메일 첨부, 메일 링크 또는 다운로드 링크로 전달합니다.

고정 셀 입력은 Office Scripts를 사용하는 설계입니다. 구현 시 사용 조직의 Excel·Power Automate 연결과 실행 권한을 확인합니다.
템플릿에 새로운 의미의 추출 항목이나 계산 로직을 추가하면 추출·검증 API 또는 스크립트 수정이 필요할 수 있습니다.
기존 지원 항목의 값·셀 주소·범위 조건 변경은 설정 데이터로 관리하는 것을 목표로 합니다.
